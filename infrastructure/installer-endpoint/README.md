# Public installer endpoint

The stable entrypoint for `get.myownsuite.org` is hard-coded to `main` and serves released source after it reaches that branch. The development entrypoint for `get-dev.myownsuite.org` reads `INSTALL_BRANCH` from its repo-owned Wrangler configuration (currently `feat/app-privacy-posture`, later `staging`). Point it at whichever branch is under test and redeploy the dev Worker (`npx wrangler deploy` from `infrastructure/installer-endpoint/dev`) before running the DigitalOcean smoke. `/install.sh` exposes either launcher for inspection. Hosted one-line installs select the `public-vps` front door, which enables automatic HTTPS and protected first-owner setup; generic `ssh-bootstrap` remains available for non-public/LAN use.

For every request, the Worker asks GitHub for the configured branch tip, validates the returned full commit SHA, and emits a launcher pinned to that SHA. The machine therefore installs one immutable snapshot even if the branch moves during installation. No GitHub or Cloudflare API token is required by the Worker for this public repository.
